# Python & Pandas Exercises

## About

This repository contains my **completed Python exercises using Pandas** in Google Colab during the **Data Technician Bootcamp**. The exercises covered a range of tasks from beginner-friendly DataFrame operations to more advanced data cleaning and analysis techniques, helping me gain confidence in manipulating and exploring datasets efficiently.

### 🧠 Skills Demonstrated

Throughout these exercises, I developed hands-on experience with:

* **Creating and exploring DataFrames** from Python collections and CSV files
* **Selecting and transforming columns and rows** using indexing, `.loc`, `.iloc`, and boolean filtering
* **Handling missing values**: identifying, filling, and dropping NAs
* **Data cleaning and preparation**, including renaming columns, removing duplicates, and sorting data
* **Calculating descriptive statistics** and aggregations to summarise datasets
* **Applying Pandas methods** in real-world style tasks, preparing datasets for analysis or reporting
